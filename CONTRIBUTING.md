# Contributing

Thanks for your interest in contributing to Multiverse.

## Ways to contribute

- Open an issue for bugs or feature requests.
- Submit a pull request with a focused change.
- Improve documentation, tests, or project tooling.
- Help with code review and project maintenance.

## Development workflow

1. Fork or branch from the default branch.
2. Keep changes focused and atomic.
3. Run the relevant tests before submitting a pull request.
4. Ensure formatting and linting checks pass for the touched Go code.

## Code standards

- Prefer clear, idiomatic Go.
- Keep changes small and easy to review.
- Add or update tests for behavior changes when practical.
- Document user-facing changes in the relevant files or changelog entries.

## Pull requests

- Describe the problem and solution clearly.
- Include context for any migration, config, or UI changes.
- Ensure the branch is up to date before opening the request.

## Community expectations

Be respectful, constructive, and considerate in discussions and code review.
