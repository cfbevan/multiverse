# Security Policy

## Supported versions

This project is under active development. Security updates are handled on a best-effort basis for the current branch.

## Reporting a vulnerability

Please do not open a public GitHub issue for security vulnerabilities.

Instead, report them privately through GitHub Security Advisories or by contacting the maintainer directly through the project repository.

If a private reporting route is not yet configured, use the repository maintainers and request a confidential advisory report.

When reporting, include:

- Summary of the issue
- Affected version or branch
- Reproduction steps or proof of concept
- Potential impact
- Any suggested remediation

We will acknowledge receipt as quickly as possible and work toward a fix and coordinated disclosure timeline.
