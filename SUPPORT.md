# Support

For bug reports, feature requests, and general questions, please use the GitHub issue tracker.

- Issues: https://github.com/cfbevan/multiverse/issues
- Wiki: https://github.com/cfbevan/multiverse/wiki

Before opening a new issue, please:

- Check whether a similar issue already exists.
- Provide a clear description of the problem or request.
- Include relevant steps to reproduce, logs, or screenshots if applicable.
- Include environment details such as Go version, OS, and database configuration when relevant.

This project is currently in active development, and support responses may vary based on scope and availability.
